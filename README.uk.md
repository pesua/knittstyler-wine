# KnittStyler на Linux (Wine)

Скрипти для запуску **KnittStyler**, Windows-програми для в'язальних машин Silver Reed, на Ubuntu через Wine. Кабель машини підключається через USB-адаптер послідовного порту.

[English version](README.md)

У репозиторії немає жодного файлу KnittStyler. Потрібна власна встановлена копія програми.

## Стан

Перевірено на Ubuntu 26.04 з Wine 10.0 (пакети дистрибутива).

| Що | Стан |
|---|---|
| Інтерфейс, кирилиця, усі вкладки | Працює |
| COM-порт | Програма відкриває COM1 і надсилає адаптеру початковий запит. Перевірено на віртуальному порту; зі справжньою машиною ще не перевірено |
| Звуки | Звук Wine виводиться через PipeWire/PulseAudio. Програма відтворює звуки під час в'язання; зі справжньою машиною ще не перевірено |
| Вбудована довідка | Працює з wine-gecko, який ставить скрипт запуску |
| Друк | Через будь-який принтер, налаштований у CUPS |

Звіти з інших машин і версій Ubuntu надсилайте в issues.

## Що потрібно

- Ubuntu або Debian, x86-64, з Wine, що запускає 32-бітні програми:
  ```
  sudo dpkg --add-architecture i386 && sudo apt update
  sudo apt install wine wine32:i386
  ```
- Доступ користувача до послідовних портів (після цього перезайти в систему):
  ```
  sudo usermod -aG dialout $USER
  ```
- Бажано видалити два пакети, що захоплюють USB-адаптери. `brltty` забирає адаптери на чипах CH340/CH341, а `modemmanager` надсилає модемні команди в кожен новий порт.
  ```
  sudo apt purge brltty modemmanager
  ```
- За бажанням: `printer-driver-cups-pdf` (PDF-принтер, див. [Відомі особливості](#відомі-особливості)) і `icoutils` (іконка програми в меню).

## Встановлення

1. Отримати скрипти:
   ```
   git clone https://github.com/pesua/knittstyler-wine.git
   cd knittstyler-wine
   ```
2. Скопіювати свою копію KnittStyler. Скрипту потрібна тека встановленої програми, у Windows це `C:\KnittStyler`:
   ```
   bundle/knittstyler --import /шлях/до/KnittStyler
   ```
   Якщо програма стоїть у віртуалці VirtualBox, `scripts/extract-from-vm.sh` копіює теку з диска віртуалки без її запуску (опис на початку скрипта).
3. Додати ярлик у меню (за бажанням):
   ```
   bundle/install-desktop.sh
   ```
4. Запускати KnittStyler з меню або командою `bundle/knittstyler`. Перший запуск створює Wine-префікс і завантажує wine-gecko (близько 55 МБ); це займає близько хвилини.

## Кабель в'язальної машини

Скрипт підключає COM1 програми до першого знайденого адаптера: спершу `/dev/serial/by-id/*`, далі `/dev/ttyUSB*`, далі `/dev/ttyACM*`. У налаштуваннях програми має бути вибраний COM1.

Щоб закріпити конкретний адаптер, скопіюйте `bundle/config/knittstyler.conf.example` у `bundle/config/knittstyler.conf` і задайте `KS_SERIAL`. Шлях `/dev/serial/by-id/...` не змінюється, коли адаптер переставляють в інший USB-порт.

## Перенесення на інший комп'ютер

`scripts/pack-bundle.sh` пакує `bundle/` разом з вашою копією програми та візерунками в `dist/knittstyler-РРРРММДД.tar.gz`. На іншому комп'ютері треба встановити залежності, розпакувати архів і запустити `knittstyler/install-desktop.sh` або `knittstyler/knittstyler`.

Wine-префікс в архів не потрапляє. Скрипт створює новий префікс на цільовому комп'ютері під тамтешню версію Wine та ім'я користувача. Візерунки, збережені в KnittStyler, лежать у `bundle/app/KnittStyler` і переїжджають разом з архівом.

## Відомі особливості

- **«There is no default printer currently selected» при запуску.** Програма вимагає принтер за замовчуванням і показує це повідомлення, коли принтера немає. Достатньо натиснути OK, і далі програма працює як звичайно. Повідомлення може відкритися під заставкою з метеликом: заставка лишається поверх інших вікон, доки повідомлення не закрите. Будь-який принтер у CUPS прибирає повідомлення; `sudo apt install printer-driver-cups-pdf` додає PDF-принтер.
- **COM2–COM32 у списку портів.** Wine сам створює ці порти для `/dev/ttyS*`. Використовуйте COM1.
- **Мова інтерфейсу.** За замовчуванням російська. Мову (`RUS`, `ENG` або `JPN`) задає `bundle/config/knittstyler-defaults.reg`; після зміни треба виконати `bundle/knittstyler --setup`.

## Як це працює

- **Wine-префікс.** 32-бітний префікс (`WINEARCH=win32`) у `bundle/prefix` створюється з нуля при першому запуску, тому завжди відповідає місцевій версії Wine.
- **Локаль.** KnittStyler — ANSI-програма на Delphi з російським текстом, тому Wine має працювати з кодовою сторінкою 1251. Скрипт запускає Wine з локаллю `ru_RU.UTF-8`. Якщо в системі її немає, скрипт без root компілює її через `localedef` у теку бандла.
- **Довідка.** Скрипт визначає версію wine-gecko, яку очікує встановлений Wine, завантажує її і ставить у префікс.
- **Файли програми.** `C:\KnittStyler` у префіксі є посиланням на `bundle/app/KnittStyler`, тому перестворення префікса (`--setup`) зберігає програму й візерунки.
- **COM-порт.** Адаптер призначається на COM1 через `HKLM\Software\Wine\Ports`.
- **Налаштування.** Файли `bundle/config/*.reg` імпортуються за абеткою під час створення префікса. Особистий `knittstyler-user.reg`, покладений туди, перекриває значення за замовчуванням; `scripts/hive-to-reg.py` експортує такий файл з гілки реєстру Windows.

## Якщо щось не працює

- Вивід Wine пишеться в `~/.cache/knittstyler/wine.log`.
- `bundle/knittstyler --setup` перестворює Wine-префікс; програма й візерунки лишаються.
- `bundle/knittstyler --winecfg` відкриває налаштування Wine для префікса (перевірка звуку, версія Windows).
- `WINEDEBUG=+comm,+serial bundle/knittstyler` записує в лог виклики COM-порту.

## Структура репозиторію

| Шлях | Зміст |
|---|---|
| `bundle/knittstyler` | Скрипт запуску |
| `bundle/install-desktop.sh` | Ярлик у меню |
| `bundle/config/` | Налаштування реєстру за замовчуванням, реєстрація шрифту, приклад конфігурації |
| `bundle/app/KnittStyler/` | Ваша копія програми (не в git) |
| `scripts/` | Копіювання програми з диска VirtualBox, експорт реєстру, пакування |
| `notes/` | Нотатки перенесення і запис обміну по COM-порту |
